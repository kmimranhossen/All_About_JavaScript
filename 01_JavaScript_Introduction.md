# 01 — Introduction to JavaScript

## What is JavaScript?

**English:** JavaScript is a programming language commonly used to make web pages interactive. It also runs on servers and in many other environments.

**বাংলা:** JavaScript একটি programming language, যা ওয়েবসাইটে interaction ও dynamic functionality যোগ করে। Browser ছাড়াও Node.js-এর মাধ্যমে server-side development করা যায়।

## HTML, CSS and JavaScript

| Technology | Responsibility |
|---|---|
| HTML | Structure / কাঠামো |
| CSS | Design / ডিজাইন |
| JavaScript | Behavior / কার্যকারিতা |

## What can JavaScript do?

- Respond to button clicks.
- Validate form input.
- Update page content without reloading.
- Fetch data from APIs.
- Build web applications and server applications.

## First JavaScript program

```javascript
console.log("Hello, JavaScript!");
```

## Add JavaScript to HTML

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>JavaScript Practice</title>
  <script src="script.js" defer></script>
</head>
<body>
  <h1>Learning JavaScript</h1>
</body>
</html>
```

Put the `console.log()` example in `script.js`.
