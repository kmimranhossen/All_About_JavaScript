## How to use

1. Study the files in order.
2. Type every example yourself.
3. Run code in the browser console or Node.js.
4. Complete the exercises before moving on.
5. Build the projects and keep improving them.

## Run JavaScript in an HTML page

```html
<script src="script.js"></script>
```

For scripts that should wait until HTML parsing is complete, you can use:

```html
<script src="script.js" defer></script>
```
