# 15 — JavaScript Projects

Build these projects in order. Use HTML for structure, CSS for design and JavaScript for behavior.

## Project 1: Counter App

Requirements:
- Display a number.
- Increment and decrement buttons.
- Reset button.
- Do not allow invalid UI states.

## Project 2: To-Do List

Requirements:
- Add a task.
- Mark a task complete.
- Delete a task.
- Show a helpful empty state.
- Optional: save tasks with `localStorage`.

## Project 3: Calculator

Requirements:
- Addition, subtraction, multiplication and division.
- Clear button.
- Handle division by zero.
- Support decimal values.

## Project 4: Quiz App

Requirements:
- Multiple-choice questions.
- Track the score.
- Show feedback after an answer.
- Show the final result.

## Project 5: Weather App

Requirements:
- Search for a city.
- Fetch weather data from a legitimate weather API.
- Show loading, success and error states.
- Keep API keys out of public client-side source code when the provider requires secret keys.
